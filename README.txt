Parameter estimation code and data:

parameters folder: contains the actual code for estimating parameters. code is 
divided up by parameter. Data and pdf sources ar in the input folders

general_scripts folder: some scripts and functions used by multiple scripts in 
the parameters folder

developer_testing folder: scripts used to test aspects of the code (may not
function out of box without directed input)
